# Python Simple Lessons

A collection of Python learning exercises and small experiments, including file handling, iterators, Flask, GUI examples, SQLite and simple games.

## Requirements

- Python 3.10+
- Install dependencies only for the example you want to run.

## Run an example

```bash
python path/to/example.py
```

For Flask examples, install Flask in a virtual environment first:

```bash
python -m venv .venv
.venv\Scripts\activate
python -m pip install flask
```

This repository contains experimental code and sample data. Review scripts before running them, especially downloaders, network tools and brute-force demonstrations.
